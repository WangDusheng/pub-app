## Design Guidelines

### Colors

| Color | Hex | Usage |
|-------|-----|-------|
| Primary | #1A73E8 | Buttons, links, main actions |
| Secondary | #34A853 | Success, confirmations |
| Warning | #FBBC05 | Alerts, warnings |
| Error | #EA4335 | Errors, delete actions |
| Background | #FFFFFF | Main background |
| Surface | #F8F9FA | Cards, modals |
| Text Primary | #202124 | Main text |
| Text Secondary | #5F6368 | Secondary text |

### Typography

| Style | Font | Size | Weight |
|-------|------|------|--------|
| Headline | Roboto / SF Pro | 24sp | Bold |
| Title | Roboto / SF Pro | 20sp | Medium |
| Body | Roboto / SF Pro | 16sp | Regular |
| Caption | Roboto / SF Pro | 12sp | Regular |

### Components

- **Buttons**: Rounded corners (8dp), filled or outlined
- **Cards**: Elevation 2dp, rounded corners (12dp)
- **Inputs**: Border radius 8dp, padding 12dp
- **Bottom Navigation**: 5 items max, labels with icons
